# Changelog

## 0.1.0 — Foundation (unreleased)

- pnpm monorepo, strict TypeScript, ESLint (with architecture boundary rules), Prettier, Vitest, Playwright, GitHub Actions.
- `@frame/core`: AppShell, Page, Container, Grid, Stack, Panel, breakpoints, component registry.
- `@frame/themes`: Zod theme schema, default + editorial presets, dark mode, density, ThemeProvider.
- `@frame/ui`: Button, Field, Input, Select, Checkbox, Dialog, Tabs, Table.
- Fullstack template: React/Vite, Fastify (JWT auth, validation, webhook signatures), Supabase migration with RLS, shared Zod schemas.
- Playground app and a responsive Playwright check.
