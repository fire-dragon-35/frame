# Contributing

1. Read [FRAME.md](FRAME.md) and [AGENTS.md](AGENTS.md); the same rules apply to humans.
2. New shared components or public API changes need an approved proposal first (see AGENTS.md).
3. Meaningful architectural decisions get an ADR in `docs/decisions/`.
4. `pnpm check` must pass. Use clear, focused commits; document breaking changes in CHANGELOG.md.
